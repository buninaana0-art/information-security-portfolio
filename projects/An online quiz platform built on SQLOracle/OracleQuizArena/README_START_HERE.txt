Oracle Quiz Arena — установка и руководство по игре

Этот файл предназначен для преподавателя, проверяющего и игрока. Приложение
открывается отдельным окном Windows. Браузер не используется. Вся игровая логика,
проверка ответов, таймеры, баллы, рейтинги и создание PDF выполняются в Oracle.
Python отвечает за графическое окно и передачу данных пакету QUIZ_PLATFORM.

Самый быстрый запуск на сервере университета

Понадобятся Windows x64, доступ к Oracle Database 12c или новее и интернет при
первой установке Python-зависимостей. Oracle Client, SQL*Plus, Docker и локальная
Oracle для этого варианта не нужны.

1. Распакуйте архив целиком в обычную папку. Не запускайте файлы прямо из ZIP.
2. Дважды щёлкните INSTALL_UNIVERSITY_SERVER.cmd.
3. При первом запуске укажите параметры подключения к Oracle:
   - Oracle host — адрес сервера;
   - Oracle port — обычно 1521;
   - Connection mode — SID или SERVICE, как указано в задании вуза;
   - Service name / SID — имя сервиса либо SID;
   - Oracle schema user — вузовский логин владельца схемы;
   - Oracle schema password — пароль этого пользователя. Во время ввода пароль
     не отображается — это нормальное поведение консоли.
4. Дождитесь сообщения Oracle Quiz Arena is ready. Окно игры откроется
   автоматически.

Писать -UseExistingDatabase не требуется: новый CMD-файл уже включает этот
режим и не запускает Docker. Для повторного запуска используйте START_GAME.cmd.
Чтобы обновить схему или восстановить демонстрационные данные, снова запустите
INSTALL_UNIVERSITY_SERVER.cmd — существующие игровые данные не удаляются.

Если требуется только установить и проверить проект без открытия окна:

.\INSTALL_UNIVERSITY_SERVER.cmd -NoLaunch

Если были сохранены неверные параметры сервера, закройте игру, удалите
python\.env и снова запустите INSTALL_UNIVERSITY_SERVER.cmd. Установщик заново
задаст вопросы о подключении. Файл python\.env содержит пароль схемы Oracle,
поэтому его нельзя публиковать или передавать вместе с проектом.

Какие права нужны в Oracle

Установщик подключается к уже существующему вузовскому пользователю и ничего не
создаёт за пределами его схемы. Этому пользователю нужны:

- CREATE SESSION;
- CREATE TABLE и квота в табличном пространстве;
- CREATE PROCEDURE;
- CREATE SEQUENCE.

Право CREATE VIEW проекту не требуется. При недостатке прав нужно показать
администратору сервера текст ошибки Oracle: самостоятельно выдать себе системные
права обычный студент не может.

Два разных вида учётных данных

Параметры Oracle вводятся один раз при установке и используются приложением для
общего подключения к схеме. После появления окна игры вводится уже игровой логин.
Это разные учётные записи.

Готовые игровые профили:

| Роль | Логин | Пароль | Назначение |
| --- | --- | --- | --- |
| Участник | QUIZ_STUDENT | Student123! | Прохождение тестов |
| Автор | QUIZ_AUTHOR | Author123! | Создание и публикация тестов |
| Администратор | QUIZ_ADMIN | Admin123! | Проверка всех данных и тестов |
| Участник с историей | DEMO_ALICE | DemoAlice123! | 12 сохранённых игр |
| Участник с историей | DEMO_BOB | DemoBob123! | 12 сохранённых игр |

Через кнопку Зарегистрироваться можно создать участника или автора. Форма
запрашивает игровой логин, имя, email, пароль и повтор пароля. Вход выполняется по
игровому логину, а не по email. Пароль хранится в Oracle как солёный SHA-256-хеш.
Создание администратора через открытую регистрацию запрещено; для демонстрации
используется готовый профиль QUIZ_ADMIN.

Руководство участника

Пройти тест

1. Войдите как QUIZ_STUDENT или зарегистрируйте роль Участник.
2. Откройте раздел Каталог.
3. На карточке теста нажмите Начать. Если попытка уже открыта, кнопка будет
   называться Продолжить.
4. Для командного теста предварительно выберите команду в списке на карточке.
5. Заполните ответ и нажмите Ответить. Таймер обновляется значением из Oracle.
6. После последнего вопроса откроется результат. Кнопка Завершить попытку
   позволяет закончить тест раньше; неотвеченные вопросы получат ноль баллов.
7. На странице результата нажмите Сохранить PDF-сертификат и выберите папку.

Поддерживаются семь форматов:

- один вариант и верно/неверно — радиокнопка;
- несколько вариантов — флажки;
- текст — строка ответа;
- число — числовое поле;
- упорядочивание — выбор позиции каждого элемента;
- сопоставление — ввод соответствия напротив каждого элемента.

Посмотреть историю и рейтинг

- Мои результаты: двойной щелчок по попытке открывает подробный результат и
  позволяет сохранить сертификат. Ниже показано сравнение со средним процентом.
- Рейтинги: выберите USER для игроков или TEAM для команд, затем период
  WEEK, MONTH или ALL и нажмите Обновить. Текущий игрок отмечен звёздочкой.
- Достижения и команды: вкладка Бейджи показывает награды. На вкладке
  Команды можно ввести название и нажать Создать команду; код из сообщения
  передайте другим игрокам. Для вступления введите полученный код и нажмите
  Вступить по коду.

Руководство автора

Войдите как QUIZ_AUTHOR или зарегистрируйте роль Автор. В левом меню появится
раздел Конструктор. Содержимое опубликованного теста менять нельзя, поэтому
полностью настройте черновик до нажатия Опубликовать.

Создать тест

1. При необходимости создайте общую категорию кнопкой Новая категория и свою
   тематику кнопкой Новая тематика.
2. Нажмите Новый тест и заполните форму:
   - PUBLIC доступен всем игрокам;
   - RESTRICTED доступен только игровым логинам из списка доступа;
   - Минут на тест задаёт общий серверный таймер;
   - Число вопросов задаёт размер попытки и не должно превышать банк;
   - IMMEDIATE показывает результат ответа сразу, AFTER_TEST — после теста,
     NEVER — не показывает разбор;
   - Адаптивный меняет сложность после ответа;
   - Командный требует выбрать команду перед стартом.
3. Выберите созданный тест в левой таблице и нажмите Добавить вопрос.
4. Укажите тип, сложность от 1 до 5, уникальный порядковый номер, баллы и при
   необходимости лимит времени вопроса.
5. Выберите вопрос в таблице и добавьте правильные данные согласно его типу.

Настроить семь типов вопросов

- SINGLE: добавьте кнопкой Вариант ответа несколько вариантов и отметьте один
  флажком Правильный вариант.
- MULTIPLE: добавьте варианты и отметьте все правильные.
- TRUE_FALSE: добавьте два варианта, например «Верно» и «Неверно», и отметьте
  один правильный.
- TEXT: нажмите Ключ ответа, выберите TEXT, заполните Допустимый текст.
  При необходимости включите учёт регистра. Можно добавить несколько ключей.
- NUMBER: нажмите Ключ ответа, выберите NUMBER, задайте число и допустимую
  погрешность в поле Допуск.
- ORDERING: для каждого варианта заполните Правильный порядок числами
  1, 2, 3....
- MATCHING: для каждого варианта заполните Ключ соответствия — текст, который
  игрок должен поставить напротив элемента.

Кнопка Изображение вопроса прикрепляет PNG, JPEG, GIF или WebP к выбранному
вопросу. В окне Вариант ответа можно прикрепить отдельное изображение варианта.
Максимальный размер одного изображения — 10 МБ.

Тематики, правила и ограниченный доступ

- Тематика: сначала создайте её верхней кнопкой, затем прикрепите к тесту.
- Правило выборки: задаёт, сколько вопросов определённой категории и сложности
  Oracle должен выбрать случайно. При наличии правил сумма количества вопросов
  в правилах должна совпадать с полем Число вопросов теста, а в банке должно
  хватать подходящих активных вопросов.
- Для RESTRICTED нажмите Выдать, введите игровой логин зарегистрированного
  участника. Отозвать удаляет логин из списка доступа.

Когда черновик полностью заполнен, нажмите Опубликовать. Oracle проверит наличие
вопросов, правильных вариантов или ключей, достаточный банк и правила выборки.
Если публикация отклонена, текст сообщения укажет, что именно не заполнено.

Руководство администратора

Войдите как QUIZ_ADMIN / Admin123!. Администратор видит те же игровые разделы
и Конструктор, но имеет расширенные права внутри Oracle API:

- видит и открывает результаты всех игроков в разделе Мои результаты;
- видит все авторские тесты и может исправлять любой тест, пока он является
  черновиком;
- создаёт общие категории, собственные тематики и новые тесты;
- выдаёт и отзывает доступ игроков к ограниченным тестам;
- публикует подготовленные тесты;
- проверяет личные и командные рейтинги, бейджи и команды.

Администратор не нужен для обычной регистрации и прохождения игры. В интерфейсе
нет удаления пользователей и таблиц, поэтому случайно удалить схему из игры
нельзя.

Что быстро показать при проверке

1. Войти как DEMO_ALICE и открыть Мои результаты: должно быть 12 попыток.
2. Двойным щелчком открыть попытку и сохранить PDF-сертификат.
3. Открыть Рейтинги, показать личный и командный режимы.
4. Открыть Достижения и команды, показать бейджи и список команд.
5. Войти как QUIZ_AUTHOR, открыть Конструктор, показать три теста и семь типов
   вопросов.
6. Создать небольшой черновик и продемонстрировать, что проверку заполнения при
   публикации выполняет Oracle.

После успешной установки повторные игровые запуски выполняются файлом
START_GAME.cmd. Кнопка Выйти завершает игровую сессию и возвращает форму входа.
Закрытие окна завершает соединение с Oracle.
